# videlboga — portfolio (GitHub Pages)

This repository contains a small static portfolio site for the GitHub profile `videlboga`. It is intended to be published via GitHub Pages (repository name `videlboga.github.io`).

Edit `index.html` and `styles.css` to customize project cards, description and assets.

To publish:

1. Create repo `videlboga/videlboga.github.io` on GitHub (or allow this assistant to create it) and push this folder to the `main` branch.
2. Pages will serve the site at `https://videlboga.github.io`.
