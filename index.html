О проекте / портфолио

Здесь собраны практические и прикладные проекты: от простых статических страниц до инструментов автоматизации и ботов. Каждый проект ориентирован на реальную пользу — экономию времени, упрощение процессов или быстрое развертывание.

Проекты

connect

Лёгкий статический landing/страница — готова к публикации на GitHub Pages.

Польза: быстрое развёртывание документации или презентации проекта без сборки; подходит для прототипов и инструкций.

HTML · Pages

kittyonsite

Небольшой фронтенд‑сайт с интерактивными компонентами и простым UI.

Польза: демонстрация практических UI-паттернов и готовая основа для презентационных страниц или мини‑приложений.

JavaScript · Frontend

cozeWebSDK

Web SDK/демо для интеграции с сервисом coze.com — примеры и простая документация.

Польза: готовые примеры ускоряют интеграцию SDK в сайты и облегчают тестирование внешних интеграций.

SDK · Docs

i3-dashboard-cyberkitty

Системный дашборд для i3: помодоро‑таймер, мониторинг системы, календарь и лаунчеры.

Польза: объединяет полезные виджеты рабочего стола — помогает следить за системой, планировать работу и быстро запускать задачи.

JavaScript · Productivity

telegram_voice_bot

Телеграм‑бот для обработки голосовых и текстовых сообщений с интеграцией OpenRouter/OpenAI.

Польза: быстрое прототипирование голосовых интерфейсов — распознавание/обработка аудио, ответы через LLM, удобен для сервисных ботов.

Python · Telegram · Voice

ai-ubuntu-manager

CLI/assistant для управления Ubuntu с подсказками на естественном языке (команда `cyberkitty`).

Польза: автоматизация рутинных админ‑задач и получение рекомендаций в виде команд — экономит время и снижает рутинизм.

Python · Automation · AI

cyberkitty119

Transkribator — продвинутый проект для транскрибации видео (Whisper) с форматированием через LLM, Docker-ready и поддержкой монетизации.

bitriximportmod

Tilda → Bitrix24 bridge: сервис, который принимает вебхуки с форм Tilda, мапит поля через mapping.json и создаёт/обновляет сделки в Bitrix24.

ReceiptScan

Telegram‑бот для OCR‑распознавания чеков (Tesseract) с настраиваемой валидацией через YAML, поддержкой PDF и Docker‑развёртыванием.

practiti

Пракрити — комплекс для йога‑студии: Telegram‑бот, веб‑панель и интеграция с Google Sheets для записи, управления абонементами и аналитики.

cyberkitty-universal-agent-platform-

Универсальная платформа агентов для оркестрации автоматизированных задач и экспериментов с агентными архитектурами.

pyrogram_session_creator

Утилита для генерации Pyrogram сессий/строк авторизации — полезна при быстрой настройке Telegram‑ботов и воркеров.

cyberkitty-polybar-launchers

Анимированные кнопки‑лаунчеры для Polybar с настраиваемыми командами и автозапуском через systemd — удобство рабочего стола.

CyberKittyUltimate

MCP‑сервер с голосовым интерфейсом и анимированными аватарами: Piper TTS, автоматизация браузера и плагин для Cursor.

obsidian-diagrams-net

Плагин Obsidian, встраивающий редактор diagrams.net — удобный способ создавать и редактировать диаграммы прямо в заметках.

Openrouter_Telegram_Commentator

Бот‑комментатор на базе ChatGPT/OpenRouter — автоматически пишет комментарии/ответы в Telegram на основе правил и шаблонов.

CyberKitty_UbuntuManager

Набор утилит для управления Ubuntu: автоконфигурации, скрипты и helper‑инструменты для системного администрирования.

llama-assistant

Fork проекта Llama Assistant — локальный AI‑ассистент с поддержкой Llama 3.2, голосом и множеством моделей; ориентирован на приватный оффлайн‑ран.

dc-translations

Коллекция переводов докладов DefCon и технических видео — удобно для локализации и подготовки материалов для озвучивания/субтитров.
